# Web Security: Cross-Site Scripting (XSS)

A concise collection of notes on XSS concepts, vulnerability types, testing techniques, and prevention methods, based on self-study and hands-on cybersecurity practice.

## Topics Covered

- Introduction to XSS
- Reflected, Stored, DOM-Based, and Blind XSS
- Same-Origin Policy (SOP)
- Security Impacts of XSS
- DOM Fundamentals: Sources and Sinks
- Injection Contexts and Filter Evasion
- XSS Prevention: Output Encoding, Sanitization, Safe DOM APIs, and CSP

**Platform:** TryHackMe

## Key Takeaways

- Understand how unsafe input handling leads to XSS.
- Identify common XSS types and injection contexts.
- Recognize unsafe DOM operations.
- Apply appropriate output encoding and sanitization.
- Understand browser security mechanisms and defense-in-depth strategies.
